# AES
Hardware and software implementation of AES algorithm. This algorithm is implemented in Verilog and C++.

## Hardware Implementation
This algorithm is implemented in finite state machine.

| Key Bits   | 128  | 192  | 256  |
|:-----------|:----:|:----:|:----:|
| LUT        | 7802 | 7476 | 8631 |
| FF         | 1715 | 1966 | 2231 |
| BRAM       | 16   | 16   | 16   |
